Prince of Persia Classic - RG34XX SP / muOS test

This is a data-free PortMaster package. Use your own Prince of Persia Classic Android 1.0 APK and matching OBB. Install popclassic.zip with PortMaster, copy the files into ports/popclassic/gamedata as named in README.md, and launch the game. First launch imports the data on the handheld and should show progress in PortMaster or on the selected console.

Please test first boot and confirm that PortMaster shows extraction progress until setup completes, then clears it. The launcher also displays the same import status message used by N.O.V.A. 2. Detailed debug logging is enabled by default for now, so attach `ports/popclassic/log.txt`. To disable traces before gameplay, set `DEBUG_LOGGING=0` in `Prince of Persia Classic.sh` and relaunch. Confirm the Android touch controls are hidden at startup by the native `SetControlInVisible()` request. Press **L1+R1** together to show the overlay and again to hide it; repeat with **L2+R2**. Check that both paired controls still send their normal game inputs. Check menu selection, gameplay controls, music/effects, saving after relaunch, and exit. At startup the mouse cursor should be hidden; use D-pad to highlight a menu option and RG B (bottom) to confirm. Press Select to show the cursor, move it with the right stick, and click with B (bottom) or A (right); press Select again to hide it. Test RG B (bottom) for jump/attack, RG Y (left) for crouch/defend, RG X (top) for interact/sheath, and RG A (right) for crouch/down outside mouse mode. Also check D-pad/left-stick movement and running, Start, right-stick cursor, and whether adaptive-VSync frame pacing feels smooth. On an RG DS running Rocknix, report whether Wayland/Mesa starts, capture the detected SDL driver/controller name from `ports/popclassic/log.txt`, and test D-pad, face buttons, both sticks, audio, save/reload, and exit. Include device, firmware version, reproduction steps, and the log. The 720x480 menu, first level, save creation/reload, audio decoding, and clean exit passed locally under QEMU; updated frame pacing, extraction display, overlay visibility, and handheld behavior need device testing.
